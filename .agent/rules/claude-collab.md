# التنسيق مع Claude

قبل أي مهمة في هذا المشروع:
1. اقرأ `AI_COLLAB.md` في جذر المشروع كاملاً، والتزم بالثوابت الموجودة فيه.
2. نفّذ المهام بالترتيب المذكور هناك.
3. شغّل `npm run verify` قبل كل مهمة وبعدها.
4. سجّل نتيجة كل مهمة في قسم «سجل التواصل» في نفس الملف.
5. لا commit ولا push ولا نشر بدون موافقة المستخدم.
